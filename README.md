## 笔记方式

每个 Task 固定四件套：

| 文件 | 内容 |
|---|---|
| `notes.md` | 骨架笔记（对照原文整理，只留结论与关键区分） |
| `concepts.html` | 概念讲解页（可交互，GitHub Pages 在线看） |
| `homework-a.html` / `homework-b.md` | 当次作业 |
