## 一、导读 10 问（能答几个答几个）

1. 模型能看什么上下文？
2. 模型能使用哪些工具？这些工具从哪里获得？
3. 这些工具在哪里执行？
4. 这个 Agent 是一次一问一答，还是可以连续对话？
5. 连续对话的话，对话能记多久？
6. 中间的工具调用由谁管理？
7. 中途被打断了怎么办？
8. Agent 能不能派生自己的子 Agent？
9. 哪些边界由 Agent 自己控制，哪些需要外部约束？
10. 事后怎么复盘、审计和测试？

## 二、Task2 三问

1. 为什么"模型对自身能力的说明"不能当证据？应该看什么？
2. Preset 改变的是"能力是否存在"还是"能力如何呈现"？两者是几件事？
3. 一个模型在纯模型 Benchmark 上很强，放进任何 Agent Runtime 都会同样强吗？为什么？

## 三、Task3 三问

1. DSH 的分层避免了哪两种极端？各自代价是什么？
2. "会话 A 新增的 Tool 影响到会话 B"——问题出在哪一层？
3. PTC 与 Standard 在源码层面的差异有多小？改变的是什么？

## 四、Task4 四问

3. 有人说"DSH 就是微内核操作系统"，这个类比哪里对、哪里不对？
4. 回顾全程：Task2 观察到的 4 套 Preset 差异，能用 Task3/4 的概念解释吗？
